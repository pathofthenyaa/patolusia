# Mini Gry PWA v2.3
- Go: przebudowana geometria planszy; kamienie są centrowane dokładnie na przecięciach, a siatka mieści się w planszy.
- Statki: nowy system ustawiania z dokiem statków.
- Wybór statku -> orientacja -> dotknięcie miejsca.
- Dotknięcie już ustawionego statku zdejmuje go z planszy, więc można zmienić orientację bez robienia miejsca na obrót.
- Losuj i Start znikają po rozpoczęciu.
- Plansza przeciwnika jest nad własną.
- Zatopione statki mają osobny wygląd.
- Usunięto zbędne Opcje/tekst ze Statków.
